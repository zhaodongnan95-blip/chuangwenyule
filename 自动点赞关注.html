🏆 全功能自动化工具（含点赞 + 关注）

BiliBiliToolPro
全自动日常任务
★ 8000+

GitHub 上 Star 数最高的 B 站自动化工具，基于 .NET（C#）调用官方 API，支持 Docker、青龙面板、GitHub Actions 等多种部署方式。其中内置了自动点赞视频与批量取关不活跃 UP 主功能，并可配合消息推送（Telegram / 企业微信等）了解每日执行结果。

点赞 / 关注相关功能
  • 自动点赞每日推荐视频
  • 批量取关不活跃 UP 主
  • 自动投币 + 分享视频
  • 每日签到（主站 + 直播 + 漫画）
  • 大会员福利自动领取
  • 多账号并行管理
  • 消息推送通知
C# GitHub Actions Docker 青龙面板

BilibiliTask
GitHub Actions 自动任务
★ 2600+

仅需 GitHub Actions，无需任何服务器即可运行的 B 站日常任务脚本，基于 Java 编写。配置好 Cookie 后，每天定时自动完成包括点赞、投币、关注等多项任务，是零运维成本入门自动化的首选。

点赞 / 关注相关功能
  • 自动点赞视频
  • 自动关注指定 UP 主
  • 自动投币
  • 自动分享视频
  • 每日签到
  • GitHub Actions 免服务器运行
Java GitHub Actions 无服务器

🌐 浏览器扩展 / 油猴脚本类

BLTH（Bilibili Live Tasks Helper）
直播任务油猴脚本
★ 1100+

通过 Tampermonkey / Violentmonkey 运行的油猴脚本，专注于 B 站直播生态的自动化任务。安装后在浏览器后台静默执行，支持自动为关注主播点赞、自动送礼物等关注互动相关操作。

点赞 / 关注相关功能
  • 自动为直播间主播点赞
  • 自动向关注主播送出礼物
  • 直播每日签到
  • 自动领取粉丝勋章亲密度
  • 天选时刻自动参与抽奖
  • 可视化配置面板
TypeScript Tampermonkey 油猴脚本

BILI_fansmedal
粉丝勋章自动点赞脚本
★ 500+

专注于 B 站粉丝勋章亲密度自动刷取的脚本，通过自动点赞和互动来提升与关注 UP 主之间的亲密度等级，适合想批量升级粉丝勋章的用户。支持青龙面板和 GitHub Actions 两种部署方式。

点赞 / 关注相关功能
  • 自动点赞提升粉丝勋章亲密度
  • 批量处理所有已关注 UP 主的勋章
  • 支持自定义目标亲密度上限
  • 支持青龙面板定时执行
  • GitHub Actions 无服务器运行

📋 批量关注 / 取关工具类

bilibili-unfollow
批量取关工具
★ 300+

专门用于 B 站批量取消关注的轻量油猴脚本。直接在 B 站网页端的关注列表页面运行，一键自动遍历并取消所有不想继续关注的 UP 主，解决手动逐个取关效率低的问题。

关注管理功能
  • 一键批量取消关注
  • 支持按条件筛选取关对象
  • 在网页端直接运行，无需安装额外软件
  • 操作可视化，实时显示进度
JavaScript 油猴脚本 Tampermonkey
