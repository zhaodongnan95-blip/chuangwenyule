🏆 全功能自动化工具（日常任务类）

BiliBiliToolPro
全自动日常任务
★ 8000+

目前 GitHub 上 Star 数最多的 B 站自动化工具。基于 .NET（C#）开发，通过调用 B 站官方 API 实现账号日常任务的完全自动化。支持 Docker、青龙面板、GitHub Actions、群晖 NAS 等多种无服务器/容器化部署方式，开箱即用，并可对接 Telegram、企业微信等消息平台接收推送通知。

主要功能
  • 每日自动签到（主站 + 漫画 + 直播）
  • 自动投币（可配置每日投多少枚）
  • 自动点赞 / 分享视频
  • 直播间自动挂机获取亲密度
  • 天选时刻自动参与抽奖
  • 大会员每月福利自动领取
  • 大会员到期自动充电（B 币券）
  • 批量取关不活跃 UP 主
  • 多账号同时管理
  • 消息推送（TG / 企业微信 / 钉钉等）
C# GitHub Actions Docker 青龙面板 群晖 NAS

🌐 浏览器扩展 / 油猴脚本类

bilibili-helper-o
浏览器扩展
★ 3900+

一款专为哔哩哔哩网站量身打造的浏览器扩展（支持 Chrome / Edge / Firefox）。它直接注入到 B 站网页中，增强网站原生功能，无需登录 API，使用门槛极低，安装即用。

主要功能
  • 替换并增强网页播放器
  • 弹幕过滤 / 屏蔽关键词
  • 推送 UP 主更新通知到桌面
  • 快捷键控制播放（倍速 / 截图等）
  • 去除广告与冗余推荐内容
  • 优化移动端网页体验

BLTH（Bilibili Live Tasks Helper）
直播任务油猴脚本
★ 1100+

一款通过 Tampermonkey / Violentmonkey 运行的油猴脚本，专注于 B 站直播生态的自动化任务。打开浏览器即可在后台静默完成直播相关的各类积分任务，无需额外服务器。

主要功能
  • 直播每日签到自动完成
  • 自动领取直播间粉丝勋章亲密度
  • 自动向关注主播送出礼物
  • 天选时刻自动参与直播抽奖
  • 自动完成直播区每日任务
  • 可视化配置面板，操作简单

📤 投稿 / 下载 / 上传工具类

biliup-app
图形化投稿客户端
★ 1400+

B 站全平台桌面投稿客户端（Windows / macOS / Linux），提供图形界面，适合不熟悉命令行的普通创作者。基于 Rust + 前端框架构建，性能优秀，安装包体积小。

主要功能
  • 图形化界面，点击上传视频
  • 支持多 P（多分 P）合集投稿
  • 投稿信息（标题 / 简介 / 标签）编辑
  • 稿件管理与状态查看
  • 断点续传，上传稳定
  • 跨平台：Win / macOS / Linux
Rust 跨平台桌面 图形界面

biliup-rs
命令行投稿 / 下载
★ 1000+

biliup 的命令行版本，适合开发者和需要在服务器、脚本中集成 B 站上传/下载功能的场景。基于 Rust 编写，性能高，可作为 CI/CD 自动化流程的一部分，实现视频制作完成后自动投稿。

主要功能
  • 命令行一键上传视频到 B 站
  • 支持多种登录方式（扫码 / Cookie / 密码）
  • 支持多 P 合集上传
  • 视频下载（配合 yt-dlp 等工具）
  • 可嵌入 Shell 脚本 / CI 流程自动投稿

📋 签到脚本 / 自动化制作类

wps_script
多平台签到脚本
★ 130+

基于 WPS 金山文档 AirScript 运行的多平台签到脚本合集，无需服务器，在 WPS 文档内即可定时触发。Bilibili 签到是其中的一个模块，与爱奇艺、百度贴吧、全民 K 歌等十余个平台的签到脚本集成在一起。

主要功能（含 Bilibili 模块）
  • B 站每日自动签到
  • 爱奇艺 / 全民 K 歌 / 贴吧等平台签到
  • 依托 WPS AirScript 定时执行
  • 无需独立服务器，依赖 WPS 云端运行
  • 脚本模块化，可按需启用
JavaScript WPS AirScript 签到脚本

排行榜视频制作自动化
★ 70+

专为 B 站排行榜周刊视频制作设计的全流程自动化脚本套件。覆盖从数据抓取、After Effects 视频渲染到自动投稿的完整工作流，是内容创作者提升生产效率的利器。

主要功能

  • PowerShell 自动化文件管理
  • 渲染完成后自动调用 API 投稿
  • 全流程无人值守，定期运行
