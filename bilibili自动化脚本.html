Bilibili 自动化脚本开源项目

以下是在 GitHub 上整理的热门 Bilibili 自动化脚本开源项目，按 Star 数排序。

BiliBiliToolPro
B 站（bilibili）全自动任务工具，支持每日签到、投币、点赞、分享、漫画签到、直播挂机、大会员福利领取、天选抽奖等，支持 Docker、青龙面板、GitHub Actions 等多种部署方式。
★ 8000+ C# GitHub Actions Docker
bilibili-helper-o
哔哩哔哩（bilibili.com）浏览器辅助扩展，可替换播放器、推送通知并进行一些快捷操作，支持 Chrome/Firefox 等主流浏览器。
★ 3900+ JavaScript Chrome Extension
biliup-app
B 站全平台投稿客户端，支持多 P 投稿、稿件编辑，界面友好，跨平台（Windows/macOS/Linux）可用。
★ 1400+ Rust 跨平台
BLTH（Bilibili Live Tasks Helper）
哔哩哔哩油猴辅助脚本，主要用于自动完成直播相关任务（如直播签到、自动送礼、天选抽奖等），支持 Tampermonkey / Violentmonkey。
★ 1100+ TypeScript Tampermonkey 油猴脚本
biliup-rs
命令行 B 站投稿与视频下载工具，提供多种登录方式，支持多 P 上传，可集成到自动化流程中。
★ 1000+ Rust CLI
BiliHelper-personal
哔哩哔哩（Bilibili）PHP 版助手，支持直播挂机、自动签到、投币等多种自动化任务。
★ 1000+ PHP Docker
BilibiliHelper
B 站自动领瓜子、直播挂机脚本，基于 Node.js，支持 Docker 部署，可实现直播间自动领取瓜子等任务。
★ 900+ JavaScript Node.js Docker
bilibili-live-helper
Bilibili 直播弹幕桌面工具，支持 Mac / Windows / Linux，可用于监控和自动响应直播间弹幕消息。
★ 560+ Vue Electron 跨平台
wps_script
WPS 签到脚本集合，适用于金山文档 AirScript 自动化执行，包含 Bilibili 等多个平台的自动签到功能。
★ 130+ JavaScript 签到脚本
BiliBiliRankingScripts
周刊哔哩哔哩排行榜视频制作自动化脚本，涵盖数据抓取、视频渲染（After Effects）、自动投稿等完整流程。
★ 70+ Python After Effects 自动投稿
